# Security policy

Do not report credentials, private endpoints, personal data, or decrypted material in a public issue. Use GitHub's private vulnerability reporting for a suspected artifact, exporter, provenance, or portable-configuration vulnerability.

Published bundles are public and must contain no secret. A credential found in an artifact is treated as exposed and rotated at its owning provider; removing or replacing the release does not restore secrecy. Existing release versions are never rewritten as remediation.
